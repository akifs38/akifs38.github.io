Yazma erişimi

Liste herkese açık olarak okunur; değişiklikleri GitHub'a yazmak için kendine ait bir erişim anahtarı (token) gerekir. Anahtar yalnızca bu tarayıcıda saklanır, siteye veya depoya yazılmaz.

  1. github.com/settings/personal-access-tokens/new adresini aç
  2. Repository access → Only select repositories → akifs38/akifs38.github.io
  3. Permissions → Repository permissions → Contents: Read and write
  4. Üretilen github_pat_… anahtarını aşağıya yapıştır
