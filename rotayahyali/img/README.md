# Görseller / Fotoğraflar

Bu klasöre kendi Yahyalı fotoğraflarınızı ekleyin. Dosyalar aşağıdaki adlarla
kaydedildiğinde site **otomatik** olarak gradient yer tutucuların yerine
gerçek fotoğrafları gösterir (kod değişikliği gerekmez).

## Beklenen dosya adları

### Kart görselleri (Gezilecek Yerler)
- `kapuzbasi.jpg` — Kapuzbaşı Şelaleleri
- `aladaglar.jpg` — Aladağlar Milli Parkı
- `derebag.jpg`   — Derebağ Şelalesi
- `kovali.jpg`    — Kovalı Şelalesi
- `barsama.jpg`   — Barsama Antik Yerleşimi
- `camlica.jpg`   — Çamlıca / Yaylalar

### Hakkında bölümü
- `hakkinda.jpg` — dikey (portre) bir manzara fotoğrafı (öneri 800×1000 px)

### Galeri
- `g-kapuzbasi.jpg`, `g-aladaglar.jpg`, `g-zamanti.jpg`, `g-hali.jpg`,
  `g-derebag.jpg`, `g-yayla.jpg`, `g-roka.jpg`, `g-kovali.jpg`, `g-barsama.jpg`

## İpuçları
- Kart ve galeri için **JPG** veya **WebP** kullanın (WebP daha küçük dosya).
  WebP kullanacaksanız HTML'deki `.jpg` uzantılarını `.webp` yapın.
- Yatay kartlar için ~1200×800 px, dikey galeri kareleri için ~800×1100 px idealdir.
- Telif hakkına dikkat edin; kendi çektiğiniz veya izinli/serbest lisanslı
  (ör. Wikimedia Commons, kurumsal görsel) fotoğrafları kullanın.
- Fotoğraf yoksa site yine de gradient tasarımlarla eksiksiz görünür.
